# NFS // CHEATBASE

Каталог чіт-кодів для серії **Need for Speed** — швидкий, адаптивний, у стилі
**Retro 2005** (фіксована сітка 980px, чорно-синьо-білий «хром», карбонове
тло, шашечки, Verdana/Tahoma).

> Поточний стан: повний основний каталог серії NFS (25 ігор, 572 коди) плюс
> бонус-розділ з іграми поза серією — Gran Turismo, Midnight Club і
> Tokyo Xtreme Racer (17 ігор, 149 кодів).

---

## 🧱 Стек

| Шар | Рішення | Чому |
|-----|---------|------|
| Розмітка | **HTML5** | нульова збірка, максимальна швидкість |
| Стилі | **Власний CSS** (дизайн-токени + компоненти) | Tailwind через CDN потребує інтернету й не підходить для продакшену; крапки немає — сайт працює офлайн |
| Логіка | **Vanilla JS** (`window.NFS`) | без фреймворків і залежностей |
| Дані | **JSON** (`data/games.json`) + JS-дзеркало (`data/games.js`) | легко редагувати, працює навіть через `file://` |
| Шрифти | Системні: Verdana / Tahoma / Arial Black | автентично для 2005-го та працює офлайн без CDN |

> ℹ️ Node.js/npm у середовищі відсутні, тому Next.js не використовувався.
> За потреби міграція на Next.js + Tailwind описана в розділі «Далі».

## ▶️ Як запустити

**Варіант A — локальний сервер (рекомендовано):**

```powershell
cd "C:\Users\Ніна\Desktop\Нова папка (2)"
python -m http.server 8141
# відкрити http://localhost:8141
```

**Варіант B — просто відкрити `index.html`** подвійним кліком.
Тут працює fallback: якщо `fetch('data/games.json')` блокується політикою `file://`,
сайт бере дані з `data/games.js` (`window.NFS_DATA`).

> ⚠️ Після редагування `data/games.json` перегенеруйте дзеркало:
> ```powershell
> python -c "import json,io; d=json.load(io.open('data/games.json',encoding='utf-8')); open('data/games.js','w',encoding='utf-8').write('window.NFS_DATA = '+json.dumps(d,ensure_ascii=False,indent=2)+';\n')"
> ```

## 🗂️ Модель даних

```jsonc
{
  "games": [{
    "slug": "nfs-most-wanted-2005",
    "title": "Need for Speed: Most Wanted",
    "year": 2005,
    "developer": "EA Black Box",
    "era": "golden",              // classic | golden | mid | modern
    "featured": true,
    "hasCodes": true,
    "accent": ["#ff7a18", "#ff2d55"],   // градієнт-заглушка «обкладинки»
    "cover": "assets/img/covers/nfs-most-wanted-2005.webp", // необов'язково
    "blurb": "…",
    "bonus": false,               // true — бонус-гра поза серією NFS
    "series": "…",                // лише для бонусних: групування на сторінці «Бонус»
    "platforms": {
      "pc": {
        "input": "text",           // text | buttons
        "howTo": ["крок 1", "крок 2"],
        "codes": [
          { "category": "Автомобілі", "name": "Усі автомобілі",
            "code": "iammostwanted", "effect": "Розблоковує всі авто",
            "verified": true }
        ]
      },
      "ps2": { "input": "buttons", "codes": [
        { "category": "Автомобілі", "name": "Syntec Ford GT",
          "code": "◀ ▶ ◀ ▶ ▲ ▼ ▲ ▼", "effect": "…", "verified": true }
      ]}
    }
  }]
}
```

* `input` — підказка платформи: `text` або `buttons`. Оскільки деякі платформи змішують паролі, CWCheat/CodeBreaker-рядки й комбінації кнопок, рендерер додатково розпізнає формат кожного коду.
* `format: "text" | "buttons"` (необов’язково) — явно перекриває визначення формату для окремого коду. Для `text` використовується моношрифт `.code-value`, для `buttons` — «клавіші» `.kbd`.
* `cover` — необов’язковий шлях до локальної обкладинки гри. Якщо поле відсутнє, картка використовує градієнт з `accent`; зображення не завантажуються із зовнішніх CDN.
* `verified: false` — код позначений плашкою «не перевірено».

Категорії: `Головний код`, `Гроші`, `Автомобілі`, `Апгрейди`, `Вініли`, `Спонсори`,
`Ігровий процес`, `Треки`, `Комбінації в меню`, `Розблокування`, `Секрети`,
`Статистика`, `Час`, `Налаштування`, `Очки та репутація`, `Музика`, `Тюнінг`, `Графіка`.

## ✅ Що вже працює

- **Головна:** Hero із live-пошуком (ігри + коди, навігація з клавіатури ↑↓/Enter), швидкий
  фільтр за платформами, сітка популярних ігор, список останніх оновлень, статистика бази.
- **Каталог:** групування за епохами (Класичні 90-х / Золота епоха / Сучасні), фільтр за
  родиною платформ, пошук.
- **Сторінка гри:** інфоблок, таби платформ із кількістю кодів, групування за категоріями,
  кнопка «Копіювати» (з підтвердженням), покрокова інструкція вводу.
- **Платформи:** огляд родин і окремих платформ, списки ігор із фільтрацією.
- **Адаптивність:** від мобільних до широких екранів, бургер-меню.
- **Бонус:** окремий розділ для ігор поза серією — з тими самими правилами збору й
  перевірки кодів. Групується за серіями: **Gran Turismo** (12 ігор), **Midnight Club**
  (4) і **Tokyo Xtreme Racer** (Street Supremacy).

Дані: **25 ігор** серії, **572 коди** (70 із них мають плашку «не перевірено» — знайдені
лише в одному джерелі). Разом із бонусним розділом — **42 гри, 721 код, 128 «не перевірено»**.
Найбільше кодів: PC (233), PS1 (72), PS2 (65) і GBA (52 — повні набори
CodeBreaker / GameShark для Underground, Underground 2, Most Wanted і Carbon: Own the
City). Коди CodeBreaker для GBA-версій UG1 / UG2 звірено з базою **libretro-database**
(RetroArch); у MW і Carbon також є комбінації кнопок для меню, які працюють без
чіт-пристрою. Для PC додано 104 коди: The Need for Speed (10), NFS II (23),
NFS III: Hot Pursuit (29), High Stakes (34) і Porsche Unleashed (8) — класичні коди
з клавіатури.
Для PS1 додано 72 коди: NFS II (30), NFS III: Hot Pursuit (19), High Stakes (8),
Porsche Unleashed (13) та оригінальний The Need for Speed (2) — паролі й комбінації кнопок.
Для PSP-версії ProStreet додано повний набір CWCheat-кодів (працюють у PPSSPP і на PSP з кастомною прошивкою). Поза серією — окремий **бонус-розділ**: **17 ігор** і **149 кодів**
(Gran Turismo — 12 ігор, 72 коди; Midnight Club — 4 гри, 75 кодів; Tokyo Xtreme
Racer — Street Supremacy, 2 коди). Серед знахідок — секретні комбінації GT4, відкриті
через 19 років після релізу, та коди Midnight Club: L.A. Remix (знайдені у 2023-му).

31.10.2026 додано **22 Action Replay-коди** для шести NDS-версій: Underground 2 (6),
Most Wanted (5), Carbon: Own the City (3), ProStreet (5), Undercover (2) і Nitro (1).
19 кодів підтверджено двома незалежними джерелами (CodeJunkies + Neoseeker, для Nitro —
Neoseeker + Cheat Happens); 3 позначено як «не перевірено». Усі шість NDS-блоків тепер
заповнені; порожніх platform-блоків у каталозі залишилося 48.

03.11.2026 додано **42 локальні обкладинки** — по одній для кожної гри каталогу.
12 з них надані користувачем, 30 взяті з LaunchBox Games Database (Box - Front).
Для Gran Turismo 4, Gran Turismo 4 Prologue і Gran Turismo 5 Prologue використано
варіанти з папки користувача. Обкладинки показуються на картках, сторінках ігор,
у каталозі, бонусному розділі, платформах і пошуку; усі зображення лежать у
`assets/img/covers/` і працюють офлайн. Градієнтний fallback збережено в рендерері
для майбутніх ігор без `cover`. Дані `1.5.1`, `?v=25`.
Деталі та відповідність файлів — `COVERS-2026-11-03.md`.

Окремо додано **Shift 2: Unleashed** (2011) з блоками PC / PS3 / Xbox 360; вбудованих
чіт-кодів у грі немає. Також додано PC-блоки для **NFS: World** і **NFS: Unbound** —
без кодів, лише з поясненням статусу.

28.10.2026 додано platform-блоки без кодів для **Hot Pursuit 2010** (PS3 / Xbox 360),
**Rivals** (PS3 / Xbox 360), **Unbound** (PS4 / Xbox One) і шести ігор **Gran Turismo**
(GT4 Prologue, GT5 Prologue, GT5, GT6, GT Sport, GT7). Загалом у каталозі 120
platform-блоків; кількість кодів не змінилася. П’ять кандидатів **Underground Rivals**
залишено в карантині, бо мають лише одне джерело.
