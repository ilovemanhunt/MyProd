# Обкладинки ігор — 2026-11-03

## Що додано

Усі **42 гри** каталогу тепер мають локальну обкладинку. Вони використовуються на
картках ігор (головна, каталог, бонус, платформи), у hero-блоці сторінки гри та як
мініатюри в пошуку. Градієнтний fallback збережено в рендерері для майбутніх ігор
без поля `cover`.

- **12** обкладинок надані користувачем.
- **30** обкладинок взяті з LaunchBox Games Database, секція **Box - Front**.
- Для **Gran Turismo 4**, **Gran Turismo 4 Prologue** і **Gran Turismo 5 Prologue**
  використано фото з папки користувача; попередні варіанти LaunchBox видалено.
- Усі файли лежать у `assets/img/covers/`; зовнішні CDN не використовуються.

## Технічні зміни

- У `data/games.json` поле `cover` заповнено для всіх 42 ігор.
- `data/games.js` синхронізовано з JSON.
- `NFS.coverImage()` у `assets/js/app.js` формує `<img class="cover-img">`.
- Картки та hero використовують `cover`, якщо він є; інакше — градієнт.
- Додано CSS для `cover-img`, `has-cover`, hero-зображення та мініатюр пошуку.
- `?v=25` у всіх п'яти HTML-файлах.
